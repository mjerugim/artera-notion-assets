# Artera Notion assets

Public images for Artera's Notion pages: page covers and page icons in the Artera Notion style. Notion only accepts
covers and icons as public web addresses, so they're hosted here.

- `covers/`: 1500 x 600 covers made from Artera's approved illustration library (navy, no text, no logo).
- `icons/`: 512 px page icons, either the Artera brandmark or a Google Material Symbols Rounded icon (weight 300) in
  Artera accent blue `#1F56C4`.

These files are made with `scripts/notion_assets.py` in the artera-brand skill and follow its rules
(`references/notion.md`). Don't edit them by hand; add new ones the same way.

The Artera logo, brandmark and illustrations are Artera brand assets. Material Symbols are by Google, under the
Apache License 2.0.

## slides/

Images the Artera Google Slides template places on its layouts (logo files and approved library illustrations, exported as PNG). Google Slides can only insert images from public URLs. Source: the artera-brand skill, `references/slides-and-decks.md`.
